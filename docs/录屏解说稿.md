# 录屏解说稿

评分要求里写明「展示里要讲清你做了什么、怎么做的、学到了什么」。这一份是照着念的稿子，
也可以直接当字幕烧进视频。全程一分半左右，跟着下面五步走。

## 口语版（照着念）

**（开场，5 秒）**

这是我这次做的东西，一个 Photoshop 面板插件，叫选区生图。解决的问题很具体：我在 PS 里框一块地方，
写一句提示词，让生图模型直接在选区里把图生出来，结果自动贴回原位。

**（拖框选，15 秒）**

先框选一块。面板会自动读到这个选框的位置和大小，不用我手填尺寸。

**（写提示词，15 秒）**

然后写提示词。张数填几张，就把这一句发几条并发请求 —— 网络请求是并发的，
所以第 2 张不用等第 1 张跑完。

**（点生成、看状态，20 秒）**

点生成。面板底部能看到每条任务走到哪一步：排队、生成中、贴回中、完成。
「贴回中」是我后来加的一个状态，一开始没有它，任务统计会算出一个 NaN，那个 bug 下面讲。

**（看贴回，15 秒）**

图回来之后，插件会把结果缩放到选区大小、对齐选区左上角，贴在新图层上，落在原位置上。
整个动作算一步，按一次 Ctrl+Z 就能撤销。

**（讲踩坑，20 秒）**

这里说两个真机上踩的坑。第一，「进行」那一栏我一开始显示的是 NaN，
回看录屏才发现的，查下来是任务状态表漏了一种状态，已经补上，也补了断言来保证不再漏。
第二，多图自动编组加白底蒙版那一步，在真机上会报错、没跑通，我没有把它写成「已完成」，
而是把错误信息补全成「卡在哪一步 + Photoshop 的原始错误码」，写在文档里等下次复现定位。

**（收尾，10 秒）**

代码、更新日志、开发记录都在仓库里，测试是一百五十项断言，每次提交都会自动跑一遍。
